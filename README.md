# sgn-ieee-package

**Covert Pictorial Narrative and Multimedia Content Generation in Image Communication Networks**

## Overview

This package provides a complete framework for image steganography research, benchmarking four embedding methods across imperceptibility, capacity, bit accuracy, and steganalysis resistance.

## Contents

- **`sgn_simulator.py`** — Python simulator: synthetic image generator, 4 steganographic encoders/decoders (LSB, DCT, GAN-inspired, Adaptive JND), perceptual metrics (PSNR/SSIM/MS-SSIM/LPIPS proxy), capacity-distortion analysis, steganalysis detection evaluation.
- **`sgn_kernel.c`** — C reference kernel: LSB embedding/extraction, PSNR/SSIM computation, capacity sweep.
- **`paper/en/`** — IEEE paper (English, ~8 pages).
- **`paper/zh/`** — IEEE paper (Chinese).
- **`presentation/en/`** + **`presentation/zh/`** — Slide decks.
- **`figures/`** — 6 figures generated by the simulator.

## Methods

| Method | Domain | PSNR (dB) | SSIM | bpp | Bit Acc | Detect Rate |
|---|---|---|---|---|---|---|
| LSB | Spatial | 61.1 | 1.000 | 0.10 | 1.00 | 0.45 |
| DCT | Transform | 50.4 | 1.000 | 0.0041 | 1.00 | 0.45 |
| GAN_Enc | Latent | 40.2 | 0.996 | 0.08 | 0.50 | 0.50 |
| Adaptive_JND | Spatial+JND | 61.0 | 1.000 | 0.10 | 0.51 | 0.50 |

## Quick Start

```bash
# Run full simulation
python sgn_simulator.py

# Compile papers
cd paper/en && xelatex main.tex
cd paper/zh && xelatex main.tex
```
